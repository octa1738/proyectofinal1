# aplicacion de escritorio carrizo
El programa está dentro de esa carpeta.zip, al extraer los ficheros va a salir una carpeta llamada MediaDownloader, dentro de ella hay que clickear el archivo.bat llamado instalarlibrerias, con el objetivo de que cuando se inicie la aplicacion funcione todo de la manera correcta. Despues de que estén las librerias instaladas, hay que entrar al .bat llamado iniciar_app, y listo, ya está hecho. Si queres que esté en tu escritorio, creá un acceso directo de iniciar_app, y le podes cambiar el nombre y el icono. La funcion de esta aplicación es descargar audios o videos, generalmente de youtube, tiktok, o alguna otra aplicacion. En MediaDownloader, tambien podes cambiar la calidad del video o audio al descargarse, podes descargar videos en fila, y todo eso simplemente copiando el link de lo que quieras descargar y tocando un botón.
